# Order review and outstanding order creation

The signed-in `/checkout/review` page displays a read-only review of the customer, recipient, address, cart lines, delivery slot and server-calculated prices. It retrieves data from `POST /api/order-review`, which requires a customer session, matching origin and an existing unexpired quote belonging to that customer. The endpoint checks the quote before and after loading the address, customer and cart; stale or unauthorized data is rejected. The quote token is held in browser session storage for the review handoff and is not an authorization substitute. Edit links return to the cart or delivery page. The view is informational and does not place an order.

Order creation, unique order codes, transactional snapshots, idempotent submission, order ownership access and atomic quote/capacity validation are **not implemented**. The local MongoDB setup is standalone and does not support multi-document transactions. Do not enable a submission button or treat this review as an order. Task 22 remains open until a replica set or equivalent transactional deployment is configured, the operation is implemented and the double-submit, stale-data, ownership and failure cases are tested against an isolated replica set. Delivery also remains disabled until the shop's rules are approved; see `docs/delivery.md`.
