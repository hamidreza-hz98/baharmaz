# Aqaye Pardakht integration status

The server-only adapter implements an isolated sandbox contract based on the provider's [official API documentation](https://aqayepardakht.ir/api/), consulted 11 November 2026. Its create and verify calls use integer tomans; the application stores integer rials and rejects non-exact conversion and provider amounts outside the documented 1,000–400,000,000 toman range. The adapter uses fixed provider HTTPS endpoints, bounded responses, a timeout, no redirects and an explicitly configured HTTPS callback. A mock transport exercises the request and response contract without contacting the provider.

`AQAYE_MODE`, `AQAYE_PIN` and `AQAYE_CALLBACK_URL` are server-only. The sandbox mode requires the explicitly configured sandbox PIN. No secret should be committed or sent to clients. Live mode is deliberately rejected by configuration and the adapter; there is no payment initiation route or callback endpoint. The sandbox PIN is not proof of a successful live sandbox test: no provider verification has been demonstrated here.

A provider callback is untrusted input and must never directly mark an order paid. Verification result code 1 is returned as verified, code 2 is kept distinct as already verified, and other responses remain unconfirmed. Future integration must persist the attempt and trusted server-side order amount before handoff, verify with the provider, reconcile already-verified and uncertain responses, and make state transitions and callbacks idempotent. Never accept an amount or order status from the browser. Do not retry an ambiguous create request blindly; it may have reached the provider.

Live readiness remains blocked by task 22: transactional order creation, immutable order amounts and ownership do not exist. Payment attempt persistence, callback handling, amount/order validation, replay protection and a real sandbox test are not implemented. Confirm the approved callback domain and provider terms before integration; use dedicated sandbox credentials and isolated test data. Run `node --conditions=react-server --test tests/payment.test.mjs` for the mock contract.
